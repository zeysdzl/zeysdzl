I'm a computer engineer working across **software engineering, QA and AI automation**. I founded and built **Davetiye Dijital**, a config-driven wedding-invitation SaaS, and I ship AI-powered products and client tooling at **[Arty Digital](https://artydigital.com.tr)**.

My habit from QA follows me everywhere: assume it breaks, then go find how. I like owning a system end to end, from architecture and automation to the edge cases nobody else thought to test. Before all that I worked on **computer vision** (YOLO, OpenCV, Raspberry Pi) and **embedded systems** (MSP430, C).
